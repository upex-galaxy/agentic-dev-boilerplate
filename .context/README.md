# .context/ - Context Engineering Directory

Este directorio contiene toda la documentación que la IA lee para trabajar en el proyecto.

## 📂 Estructura

```
.context/
├── idea/           FASE 1: Constitución del negocio
├── PRD/            FASE 2: Product Requirements Document
├── SRS/            FASE 2: Software Requirements Specification
├── PBI/            FASES 2-4: Product Backlog Items
├── TAE/            FASE 7: Test Automation Engineering
└── guidelines/     FASES 5-6: System prompts para IA
```

## 🚀 Cómo empezar

1. **FASE 1**: Usa prompts de `.prompts/fase-1-constitution/` para generar archivos en `idea/`
2. **FASE 2**: Usa prompts de `.prompts/fase-2-specification/` para generar archivos en `PRD/`, `SRS/`, `PBI/`
3. **FASE 3**: Usa prompts de `.prompts/fase-3-shift-left-testing/` para generar test plans
4. **FASE 4**: Usa prompts de `.prompts/fase-4-planning/` para generar implementation plans
5. **FASE 7**: Usa prompts de `.prompts/fase-7-tae/` para generar docs de testing
