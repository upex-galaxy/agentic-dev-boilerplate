# Exploratory Testing Guidelines

## Propósito
Encontrar bugs rápido sin perder tiempo en automatización prematura.

## Flujo
1. Smoke test (5 min) - validar deployment
2. Test charter (15 min) - planear exploración
3. Session (60-90 min) - explorar funcionalidad
4. Bug reports - reportar hallazgos

## Técnicas
- Tours (recorrer la aplicación)
- Pairing (explorar en dupla)
- Personas (usar diferentes user personas)
- Edge cases (inputs inválidos, límites)

## Output esperado
- Bugs encontrados temprano
- Feedback de UX
- Ideas para casos de prueba automatizados
