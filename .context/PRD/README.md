# FASE 2: Product Requirements Document (PRD)

Este directorio contiene los requerimientos de producto desde la perspectiva de negocio.

## 📄 Archivos a generar

Usa los prompts de `.prompts/fase-2-specification/` para crear:

1. **`executive-summary.md`** - Problem statement, solución, KPIs, target users
   - Usa: `.prompts/fase-2-specification/prd-executive-summary.md`

2. **`user-personas.md`** - 2-3 perfiles de usuarios detallados
   - Usa: `.prompts/fase-2-specification/prd-user-personas.md`

3. **`mvp-scope.md`** - Épicas y user stories del MVP (in/out scope)
   - Usa: `.prompts/fase-2-specification/prd-mvp-scope.md`

4. **`user-journeys.md`** - Flujos de usuario (happy path + edge cases)
   - Usa: `.prompts/fase-2-specification/prd-user-journeys.md`

## 🎯 Output esperado

Al completar esta sección tendrás:
- 4 archivos con la visión completa del producto
- Base para SRS (requerimientos técnicos)
- Claridad sobre qué construir en el MVP
