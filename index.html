Los planos de cómo este repo construye software con IA.

Este repo defiende una regla antes que cualquier otra: plan antes de código. Cada skill produce un plano por escrito antes de escribir una sola línea — un PRD, un DESIGN.md, un mockup, un impl plan, un epic. Este hub es la versión legible de esos planos: cómo piensa cada skill, qué archivo espera de vos, y qué te devuelve.

¿Por qué tantas cards "Próximamente"? Este hub se construye deck por deck, no de una — cada uno se re-verifica contra la skill real antes de publicarse (ver packages/decks/README.md). El orden de construcción está en packages/decks/ROADMAP.md: los dos P0 pendientes son los siguientes.

Sobre este hub. Vive en packages/pages-home/ y packages/decks/ del propio repo — carpetas boilerplate-only, podadas por el scaffolder (create-agentic-dev) antes de llegar a un proyecto consumidor. Cada deck es un HTML autocontenido, sin build, sin requests externos. Publicado por .github/workflows/pages.yml en cada push a main.
